## 問28

OSPFでは、ルータを一意に識別するためにRouter‑IDが設定されます。
OSPFの設定で`router-id <router-id>`が明示的に設定されていない場合、ルータは自動的に選出しますが、
その時に次のインタフェースとIPアドレスの組み合わせの中で、最も優先度が低いものはどれでしょうか？
NW機器のOSは、Cisco IOS系、VyOSとします。

### 選択肢（択一選択）

1. lo0 : 10.0.0.250
2. lo1 : 192.168.100.1
3. Gig0/0 : 172.16.1.218
4. Gig0/1 : 172.254.100.5

### 正解

3

### 解説

OSPFにおける Router-ID の自動選出ルールと、IPアドレスの大きさ比較を整理して考える問題です。  

Cisco IOS系、VyOSが動作しているネットワーク機器では、OSPF Router-ID の自動選出優先順位は下記の通りです。
1. 手動設定（router-id コマンドで明示的に指定された値）※最優先
2. Loopback（論理）インタフェースの中で最も大きいIPアドレス
3. Up状態の物理インタフェースの中で最も大きいIPアドレス

この自動選出優先順位通りに選択肢を当てはめると、

まず、「Loopback インタフェース」は「物理インタフェース」よりも優先されるため、
選択肢 1,2のLoopbackグループ > 選択肢 3, 4の物理インタフェースグループという順番になります。

次に、各グループ内でIPアドレスの大きさを比較すると、
Loopbackグループ（選択肢 1, 2）  
選択肢1(10.0.0.250) < 選択肢2(192.168.100.1)

物理インタフェースグループ（選択肢 3, 4）  
選択肢3(172.16.1.218) < 選択肢4(172.254.100.5)

そのため、自動選出優先順位は下記の通りになります。

Loopbackグループ（選択肢 1, 2）  
lo1 : 192.168.100.1 → Loopbackの中でIPアドレスが最大（全体で優先度 1位・Router-IDに選出）  
lo0 : 10.0.0.250 → Loopbackの中でIPアドレスが小さい（全体で優先度 2位）  

物理インタフェースグループ（選択肢 3, 4）  
Gig0/1 : 172.254.100.5 → 物理の中でIPアドレスが最大（全体で優先度 3位）  
Gig0/0 : 172.16.1.218 → 物理の中でIPアドレスが小さい（全体で優先度 4位＝最も低い）  

よって、3. Gig0/0 : 172.16.1.218　が答えとなります。
