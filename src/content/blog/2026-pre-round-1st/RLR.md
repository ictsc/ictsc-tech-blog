## 問23

あるルーターに、以下のIPv6ルーティングテーブルが設定されています。

```text
2001:db8:1000::/48        via 2001:db8:ffff::1
2001:db8:1000:1200::/56   via 2001:db8:ffff::2
2001:db8:1000:1230::/60   via 2001:db8:ffff::3
2001:db8::/32             via 2001:db8:ffff::4
::/0                      via 2001:db8:ffff::5
```

以下の宛先IPv6アドレスを持つパケットを受信した場合、それぞれ転送先として使用されるネクストホップの組み合わせとして、最も適切なものを選びなさい。

1. `2001:db8:1000:abcd::1`
2. `2001:db8:1000:123b::abcd`

|     | 1                  | 2                  |
| --- | ------------------ | ------------------ |
| A   | `2001:db8:ffff::1` | `2001:db8:ffff::2` |
| B   | `2001:db8:ffff::1` | `2001:db8:ffff::3` |
| C   | `2001:db8:ffff::2` | `2001:db8:ffff::3` |
| D   | `2001:db8:ffff::4` | `2001:db8:ffff::2` |

### 選択肢（択一選択）

1. A
2. B
3. C
4. D

### 正解

2

### 解説

IPルーティングでは、宛先に一致する経路のうち、プレフィックス長が最も長い経路が選択される。

以下の3つの経路は、先頭3ブロックが`2001:db8:1000`で共通しており、第4ブロックの範囲が異なる。第5ブロック以降の値は問わない。

| 経路 | 第4ブロックの範囲（16進数） |
| --- | --- |
| `2001:db8:1000::/48` | `0000～ffff` |
| `2001:db8:1000:1200::/56` | `1200～12ff` |
| `2001:db8:1000:1230::/60` | `1230～123f` |

- 宛先1：`/56`と`/60`の経路には一致せず、最も長く一致する経路は`2001:db8:1000::/48`となる。ネクストホップは`2001:db8:ffff::1`である。
- 宛先2：第4ブロックの`123b`が`1230～123f`の範囲に含まれるため、`2001:db8:1000:1230::/60`が最も一致するプレフィックス長が長い経路になる。ネクストホップは`2001:db8:ffff::3`である。

したがって、適切な組み合わせはBであり、正答は **2** である。
