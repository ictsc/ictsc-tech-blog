## 問2

AS65000のRT-A と、AS65001のRT-B1, RT-B2がeBGPでピアリングしている。 RT-B1, RT-B2がそれぞれ以下の経路をRT-Aに広報しているとき、RT-Aにおける 192.0.2.0/24, 203.0.113.0/24 それぞれのベストパスとなるNextHopアドレスを答えよ。 なお、RT-AにおけるBGPピアの確立と経路の受信は RT-B2 → RT-B1 の順であった。 また、ルーターIDはそれぞれのloopbackアドレスであり、BGPセッションは接続IFのアドレスで確立している。 RT-AではLP, MEDの付与や書き換えは行なっていない。 これらのルーターはStandards TrackにあるRFCに準拠したアルゴリズムで動作している。

```bash
RT-B1
192.0.2.0/24
  type external
  Nexthop: self
  AS path: [65001] 65100 I
203.0.113.0/24
  type external
  Nexthop: self
  MED: 100
  AS path: [65001] ?
```

```bash
RT-B2
192.0.2.0/24
  type external
  Nexthop: self
  AS path: [65001] 65100 I
203.0.113.0/24
  type external
  Nexthop: self
  MED: 110
  AS path: [65001] I
```

![](/images/2026-pre-round-1st/jjy-topo.png)

### 小問(1)

192.0.2.0/24 のベストパスとなるNextHopアドレスを答えよ。

#### 正解（想定解答）

`198.51.100.1`

### 小問(2)

203.0.113.0/24 のベストパスとなるNextHopアドレスを答えよ。

#### 正解（想定解答）

`198.51.100.1`

### 解説

この問題はBGPのベストパス選択アルゴリズムにおいて、BGPパスアトリビュート等がどの順で評価されるかを問うものです。
この問題ではメーカー独自実装等については扱わず、Standards TrackにあるRFC、つまりRFC4271, RFC5004に従ったアルゴリズムを扱います。

#### 小問(1)

以下の表のとおり評価され、経路受信が先であったRT-B2から受信した経路が選出され、Peerアドレスである `198.51.100.1` がNextHopとなる。

| Local Route か否か   | Local Route でない  | Local Route でない  | 次の項目で評価  |

#### 小問(2)

以下の表のとおり評価され、ORIGINアトリビュートがIGPであるRT-B2から受信した経路が選出され、Peerアドレスである `198.51.100.1` がNextHopとなる。

### 講評

小問(1)では、問題文に「Standards TrackにあるRFCに準拠」するとあるため、この問題ではRFC4271だけでなくRFC5004も適用されるものとして解く必要があります。
しかし、RFC4271のみを適用し「経路の古さ」を適用しないチームが多く見受けられ、 `198.51.100.3` と解答して正答したチームと `198.51.100.1` と解答したチームがおよそ半分ずつで正答率は半分程度でした。
一部、loopbackアドレスを解答しているチームもありましたが、eBGPでは通常BGPピアを確立しているアドレスをNextHopとして用いるため、 `198.51.100.3` が正解となります。

小問(2)は、MEDよりもORIGINアトリビュートが優先されることに気付けるかを問う意図で出題した問題でした。
いずれのチームもこの点については気づけたようで、 `198.51.100.3` と解答したチームはありませんでした。
しかし、アドレスをTypoして `192.51.100.1` やloopbackアドレスを解答したチームがいくつか見受けられました。
この問題ではRFC5737で定められた例示用アドレスを用いており、その一つであるTEST-NET-2が `192.51.100.0/24` ではなく `198.51.100.0/24` であることを見落としていたようです。
