## 問30

DHCP では、yiaddr などのフィールドとオプションで IP アドレスの割り当てや通信に必要な情報の伝達を行います。
下記の情報を伝達する際のオプション番号の組み合わせはどれですか？

伝達内容: Router , Time Server , Domain Name , IP Address Lease Time

### 選択肢（択一選択）

1. 1,21,24,56
2. 8,15,31,45
3. 3,4,15,51
4. 10,18,25,36

### 正解

3

### 解説

DHCPにおけるオプション番号と、それぞれの伝達内容を整理して考える問題です。  
DHCPでは、IPアドレスの割り当てだけでなく、ルーターやタイムサーバーなど、ネットワーク通信に必要な情報をオプション番号によって通知します。  

各情報に対応するオプション番号は下記の通りです。  
1. Router（ルーター）：オプション番号 3  
2. Time Server（タイムサーバー）：オプション番号 4  
3. Domain Name（ドメイン名）：オプション番号 15  
4. IP Address Lease Time（IPアドレスのリース期間）：オプション番号 51  

この対応関係を選択肢に当てはめると、  
まず、「Router」はオプション番号 3、「Time Server」はオプション番号 4 となるため、この2つの番号が含まれている選択肢を探します。  
次に、「Domain Name」はオプション番号 15、「IP Address Lease Time」はオプション番号 51 であることを確認します。

各選択肢を比較すると、次のようになります。
- 選択肢 1：1, 21, 24, 56 → 必要なオプション番号が一致しない
- 選択肢 2：8, 15, 31, 45 → オプション番号 15 は一致するが、ほかが一致しない
- 選択肢 3：3, 4, 15, 51 → 4つすべて一致する
- 選択肢 4：10, 18, 25, 36 → 必要なオプション番号が一致しない

そのため、正しい組み合わせは以下の通りになります。

伝達内容	オプション番号
Router	3
Time Server	4
Domain Name	15
IP Address Lease Time	51

よって、3. 3, 4, 15, 51 が正解となります。
