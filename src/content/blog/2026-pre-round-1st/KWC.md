## 問42

以下のようにCiscoルータが設定されています。

```text
! Internal Network: 192.168.10.0/24
interface GigabitEthernet0/0
 description Internal Network
 ip address 192.168.10.1 255.255.255.0
 ip nat inside
!
! External Network: 203.0.113.0/24
interface GigabitEthernet0/1
 description External Network
 ip address 203.0.113.1 255.255.255.0
 ip nat outside
!
ip nat inside source static 192.168.10.10 203.0.113.10
!
access-list 10 permit 192.168.10.0 0.0.0.127
ip nat pool POOL-A 203.0.113.100 203.0.113.109 netmask 255.255.255.0
ip nat inside source list 10 pool POOL-A
!
access-list 20 permit 192.168.10.128 0.0.0.127
ip nat pool POOL-B 203.0.113.200 203.0.113.209 netmask 255.255.255.0
ip nat inside source list 20 pool POOL-B
```

ネットワーク構成は以下の通りです。

- Internal Network：`192.168.10.0/24`
- External Network：`203.0.113.0/24`

Internal Network上の以下の3台のホストからExternal Networkを通して外部のネットワークのホストへ通信を行いました。

- PC-A：`192.168.10.20`
- PC-B：`192.168.10.200`
- PC-C：`192.168.10.10`

このとき、それぞれの通信がExternal Networkへ送信される際に使用される送信元IPアドレスの組み合わせとして、最も適切なものを1つ選びなさい。

|     | PC-A                 | PC-B                 | PC-C                 |
| --- | -------------------- | -------------------- | -------------------- |
| A   | `203.0.113.200～209` | `203.0.113.10`       | `192.168.10.10`      |
| B   | `192.168.10.20`      | `203.0.113.100～109` | `203.0.113.200～209` |
| C   | `203.0.113.10`       | `192.168.10.200`     | `203.0.113.100～109` |
| D   | `203.0.113.100～109` | `203.0.113.200～209` | `203.0.113.10`       |

### 選択肢（択一選択）

1. A
2. B
3. C
4. D

### 正解

4

### 解説

この設定は、内部から外部へ送信されるパケットの送信元IPアドレスを、静的NATまたは動的NATによって変換するものである。
各ホストに適用されるルールは、静的NATの対応関係と、動的NATで参照するアクセスリスト（ACL）から判断できる。

本設定では動的NATの変換対象を指定するために、2つのACL（`access-list`）が使用されている。
ACLの設定にはワイルドカードマスク表記が用いられており、ビットが0の部分は一致を確認し、1の部分は照合対象から除外する。`0.0.0.127`では末尾の7ビットが照合対象から除外されるため、それぞれのACLに一致する送信元IPアドレスの範囲は以下の通りである。

| ACLの設定 | CIDR表記 | 一致する送信元IPアドレスの範囲 |
| --- | --- | --- |
| `access-list 10 permit 192.168.10.0 0.0.0.127` | `192.168.10.0/25` | `192.168.10.0～192.168.10.127` |
| `access-list 20 permit 192.168.10.128 0.0.0.127` | `192.168.10.128/25` | `192.168.10.128～192.168.10.255` |

各ホストに適用されるNATは以下の通りである。

- PC-A（`192.168.10.20`）はACL 10に一致するため、`POOL-A`を使用する動的NATが適用される。送信元IPアドレスは`203.0.113.100～203.0.113.109`のいずれかに変換される。
- PC-B（`192.168.10.200`）はACL 20に一致するため、`POOL-B`を使用する動的NATが適用される。送信元IPアドレスは`203.0.113.200～203.0.113.209`のいずれかに変換される。
- PC-C（`192.168.10.10`）には、`ip nat inside source static 192.168.10.10 203.0.113.10`による静的NATが適用される。動的NAT用のACL 10にも一致するが、この設定では静的NATが優先されるため、送信元IPアドレスは`203.0.113.10`に変換される。

以上より、PC-Aは`203.0.113.100～109`、PC-Bは`203.0.113.200～209`、PC-Cは`203.0.113.10`となり、組み合わせはDである。したがって、正答は **4** である。
